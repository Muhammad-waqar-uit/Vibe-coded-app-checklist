# Contributing

Thanks for helping. Keep it simple:

1. Fork the repo and create a branch.
2. Keep the numbering in README.md stable. Add new topics at the end of a section with a letter suffix (for example 25a) so existing numbers do not shift.
3. Each item needs a topic name and one concrete todo a developer can act on.
4. Stack specific tips (Next.js, Supabase, Firebase, Solidity, Django and so on) are welcome as short sub-bullets.
5. Open a pull request with a one line description of the change.
